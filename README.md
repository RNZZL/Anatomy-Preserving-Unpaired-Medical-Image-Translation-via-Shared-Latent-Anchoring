# Anatomy-Preserving Unpaired Medical Image Translation via Shared Latent Anchoring

**NeurIPS 2026**

Zhilin Zou, Hieu Le, Saumya Gupta, Jingyi Xu, Prateek Prasanna, and Chao Chen

Official repository for our two-stage framework for anatomy-preserving unpaired medical image translation, evaluated on OCT-to-OCTA and brain MR-to-CT synthesis.
